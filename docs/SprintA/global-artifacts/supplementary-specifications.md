# Supplementary Specification (FURPS+)

## Functionality

### User Management:

Admins can register, edit, and delete profiles for backoffice users (doctors, nurses, technicians) and patients. Patients can self-register and manage their profiles.

### Appointment Scheduling:

Doctors can request, update, and delete operation requests. The system schedules surgeries based on availability and optimizes schedules.

### 3D Visualization: 

Real-time 3D visualization of hospital resources, including room availability and equipment.

### GDPR Compliance:

Ensures data protection and consent management, allowing users to exercise their rights under GDPR.

### Business Continuity:

Includes a Business Continuity Plan (BCP) to ensure system resilience and fail over capabilities.

## Usability

### User Interface:

Web-based interface for backoffice and patient interactions, with role-based access control.

### Ease of Use:

Intuitive navigation and clear workflows for managing appointments, user profiles, and resources.

### Accessibility:

Ensures that all users, including those with disabilities, can access and use the system effectively.

## Reliability

### Data Integrity:

Ensures that all data, especially sensitive patient information, is stored securely and accurately.

### System Availability:

High availability with minimal downtime, supported by the BCP.

### Error Handling:

Robust error handling to manage and log system errors, ensuring smooth operation.

## Performance

### Scalability:

Capable of handling a growing number of users and appointments without performance degradation.

### Response Time:

Fast response times for user interactions, including real-time updates in the 3D visualization module.

### Optimization:

Efficient scheduling algorithms to optimize resource usage and minimize waiting times.

## Supportability

### Documentation:

Comprehensive documentation for users and administrators, including user manuals and technical guides.

### Maintenance:

Regular updates and maintenance to ensure the system remains secure and functional.
